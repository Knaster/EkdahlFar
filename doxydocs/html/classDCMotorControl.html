void DCMotorControl::addTachoFreq ( float  freq)
private

Adds a tachometer value to the tachometer buffer, given in Hertz.

Advances the tachoFreq index counter tachoFreqIndex and increases tachFreqCount if it has not yet reached tachoFreqLength. Values outside of the range defined by tachoFreqPermissibleMAX and tachoFreqPermissibleMIN are set to 0
