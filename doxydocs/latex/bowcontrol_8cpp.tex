\doxysubsection{Detailed Description}
High level bow control functions

Need to have different modes for automatic or manual pressure and speed

Current behavior\+: if run if pid ON do nothing as the interrupt driven PID function will set speed to pid\+Target\+Speed else reset PID set\+Tilt manual\+Tilt\+PWM else reset PID set bow speed to 0

tilt is set immediately by either set\+Manual\+Tilt or set\+Pressure\+Baseline \begin{DoxyRefDesc}{Todo}
